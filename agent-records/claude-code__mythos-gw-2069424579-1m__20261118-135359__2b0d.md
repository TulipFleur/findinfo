## P1

**1. JS 待处理项仍报 complete**
- 停止条件（findinfo.py 轮末）：`new_domains == 0 and js_pending == 0` 才停；有 pending 且还有轮次就继续
- 最终判定：新增 `js_queue_pending` / `js_queue_failed` 分支 → `partial` + exit 5
- 实测（真实提取器 + 模拟 HTTP，41 个 JS、预算 40）：第 1 轮 40 个 / pending=1 / outcome=partial；
  第 2 轮只抓剩余 1 个（HTTP 累计 41 次，未重复）

**2. partial 未传到最终状态**
- `_stage`：先算 outcome 再写断点。partial/budget 写 `steps.status=partial`（可重跑），只有 succeeded 写 `done`
- `coverage.stage_states` 尊重 outcome：partial 不再被标 succeeded
- 新增断言：partial 阶段断点为 `partial`，succeeded 阶段仍为 `done`

**3. JS 队列跨 scope 领取**
- `js_claim(limit, allow_urls, scope)`：只认本次工作集/scope 内的行
- `js_stats(scope)`：统计同样按 scope 过滤，别的 target 的残留不会让本次看起来未完成
- 这是评审指出的"新队列引入的回归"，已修

**4. 硬超时不杀子进程 / 不覆盖旧结果**
- `_timeout()` 重写：先写 attempt 归属的 failed + result/coverage，再 `_kill_children()`
  （psutil 优先，stdlib 走 wmic//proc 兜底），最后 `os._exit(124)`
- 注意顺序：不能 `kill_tree(os.getpid())`，那会在写盘前把自己杀掉
- 实测：attempt-1 留有 complete 的 summary，attempt-2 硬超时 3s →
  进程退出码 124、`result.status=failed`、`coverage.complete=False`

## P2

**5. resume 零预算删错参数**
- 原实现 `[a for a in out if a != flag and _argv_value(out,flag) != a]`：
  `--time-budget 0` 会把 argv 里所有等于 "60" 的元素删掉，包括无关的 `--tool-timeout 60`
- 改为 `_remove_argv_flag()`：按位置删除 flag + 它自己的 value
- `task_timeout` 顶层字段：显式给 0 时清零（原先旧值残留）
- 实测：`--time-budget 0 --task-timeout 0` → time-budget 删除、tool-timeout 仍 60、task_timeout=0

**6. 并发去重非原子**
- 新增 `jobs.start_lock(key)`（复用 `_Lock` 的 O_CREAT|O_EXCL，按 dedupe key 分锁）
- `_start_background` 的"查 inflight → 建 run dir → spawn"整体进临界区
- 实测：两个并发相同提交 → 只创建 1 个 run dir、返回同一个 run_id

**7. 数据模型未贯穿交付**
- `ipagg`：`if not ips: return` 提前返回发生在读 asset_links 之前 → 改为先查关联表
- `extract` 发现：`api_paths`/`api_hosts`/`secrets`/`domains`/`ips` 写入 `summary.extract_findings`，
  不再只存在于一次性 stdout
- 恢复启动：`update_state` 清掉上一 attempt 的 result/coverage，改为 `status=running, reason=resume_started`

**8. 入口与文档不一致**
- `prompts/AGENT.md`：删除"entity/crawl/probe/ports/vhost/brute/subs 一律 --background"
  （这些子命令没有该参数，加了 rc=2）；明确只有 `run` 支持
- `docs/TOOLS.md`：`state=done` → `state=completed`，并注明终态只有 completed/failed/cancelled
- `cmd_report`：`--run` 属于别的 task 且本进程没带 `--task` 时**报错**并给出正确命令，
  不再静默读共享库返回空报告
