## 改了什么

涉及文件：

- `AGENT.md`（新增）— 多 agent 协作规则：重大修改的定义、记录文件命名规则、并发协作约定、会话最小动作清单
- `scripts/agent-record.py`（新增）— 记录生成器，保证命名唯一
- `agent-records/`（新增目录）— 每条记录一个文件

新增命名契约：

```
<agent-slug>__<model-slug>__<YYYYMMDD-HHMMSS>__<uniq4>.md
```

`uniq4` 为 4 位随机十六进制；分配时若同名文件已存在则重掷（最多 64 次），**绝不覆盖**已有记录。

脚本用法：

- `python scripts/agent-record.py --agent A --model M --summary S [--files ...] [--kind K]`
- `--dry-run` 只打印路径不落盘
- `--list` 列出最近记录
- `--check` 校验全部记录是否符合命名契约（返回 1 表示有违规）
